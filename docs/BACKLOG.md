# Tablero inicial (crear como Issues)

Copia cada línea como un Issue y asígnala a un integrante. Etiquetas sugeridas: `enhancement`, `bug`, `docs`.

## Pruebas (primero)
- [ ] Probar con 3 a 5 personas usando `docs/PRUEBAS.md`
- [ ] Registrar cada fallo con la plantilla "Fallo encontrado en una prueba"
- [ ] Corregir los fallos de gravedad 2 y 3

## Cliente
- [ ] Chat o mensajes entre cliente y artesano
- [ ] Mapa con puntos de recolección de retazos
- [ ] Guardar diseños favoritos
- [ ] Filtrar artesanos por ciudad, plazo y calificación

## Artesano

- [ ] Cotización propia antes de aceptar el pedido
- [ ] Calendario de entregas con alertas
